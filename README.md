# bake-watermark: Typst Plugin for Image Watermarking

## Overview
This project provides a Typst plugin implemented in Rust and compiled to WebAssembly (WASM) that watermarks images by baking the watermark directly into the image pixels. The plugin exports a function `bake_watermark` that takes image bytes, watermark text bytes, and an opacity byte, and returns the watermarked image as PNG bytes.

## Usage
In your Typst document, you can use the plugin as follows:

```typst
#let image-processor = plugin("bake_watermark.wasm")

#let secure-image(img-path, watermark-text: "CONFIDENTIAL", opacity: 128, width: 100%) = {
  let raw-bytes = read(img-path, encoding: none)
  let baked = image-processor.bake_watermark(
    raw-bytes,
    bytes(watermark-text),
    bytes((calc.clamp(opacity, 0, 255),)),
  )
  image(baked, width: width)
}

// Example usage:
#secure-image("input.png", watermark-text: "PROPERTY OF ACME", opacity: 100)
```

## Project Structure
- `src/lib.rs`: Rust source code for the WASM plugin
- `fonts/font.ttf`: Embedded font used for rendering the watermark text (Liberation Sans)
- `main.typ`: Example Typst document demonstrating the plugin usage
- `input.png`: Sample input image
- `main.pdf`: Generated output PDF with watermarked image
- `bake_watermark.wasm`: Compiled WASM plugin (generated by `cargo build --release`)

## Dependencies
The plugin relies on the following Rust crates:
- `wasm-minimal-protocol`: For interfacing with Typst's plugin system
- `rusttype`: For rendering TrueType font glyphs
- `image`: For loading, manipulating, and saving images

## Building
To compile the WASM plugin, run:
```sh
cargo build --release
```
The resulting WASM file will be located at:
`target/wasm32-unknown-unknown/release/bake_watermark.wasm`
Copy this file to your project root (or adjust the path in your Typst document).

## How It Works
1. The plugin loads the input image from the provided bytes.
2. It loads the embedded font (Liberation Sans) and calculates the appropriate font size so that the watermark text spans approximately 60% of the image width.
3. The text is centered horizontally and vertically on the image.
4. For each glyph, the plugin blends white text at the specified opacity onto the image.
5. The modified image is encoded as PNG and returned as bytes.

## Notes
- The watermark text is rendered in white. You can modify the color in the source code if needed.
- The opacity value should be between 0 (fully transparent) and 255 (fully opaque).
- The plugin currently only supports PNG output, but the input can be any format supported by the `image` crate (PNG, JPEG, etc.).
